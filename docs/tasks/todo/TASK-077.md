# TASK-077: Digital release forms and consent
## Priority: MEDIUM | Added by the owner on 2026-10-13
## Files allowed: new lib/releases/*, app/releases/*, a new migration

## Why
Productions need signed model releases and location releases before they can
use the footage. Paper forms get lost. Stored with the booking, they also help
with POPIA (recorded, specific consent).

## Plan
1. Templates: model release (adult, minor with guardian), location release,
   crew work-for-hire. Reviewed by a lawyer before use.
2. Sign on a phone: name, ID or passport last digits, signature, photo of the
   person (optional), date, place. Signed copy emailed to the signer.
3. Stored per booking; the production downloads all releases in one zip.
4. Withdrawal of consent recorded (POPIA right), with what that means for
   footage already used explained in the form.

## Watch out
Signed forms hold personal information: private bucket, owner-only access,
never the policy mistake fixed in F1 (verification docs).
